Drop ordered microscopy images here (e.g. t00.png, t01.png ...) progressing from
sparse to dense. The CV service picks `samples[image_index]` each time a run is
imaged, so confluence rises across the run. Public sources: Sartorius Cell
Instance Segmentation (Kaggle), LIVECell, BBBC. With Cellpose installed and
CV_MODE=real, these drive the real confluence readings.
